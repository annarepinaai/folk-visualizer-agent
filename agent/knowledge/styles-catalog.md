# Каталог визуальных стилей

Используй для выбора направления при первом разговоре по проекту.

---

## По настроению

| Стиль | Ощущение | Ключевые материалы | Свет |
|-------|----------|-------------------|------|
| **Japandi** | Тихо, достоинство, пустота как ресурс | светлый ясень, белая штукатурка, натуральный лён | рассеянный северный свет |
| **Wabi-sabi** | Несовершенство как красота, время как материал | патинированная латунь, необработанное дерево, потрескавшийся камень | боковой рассекающий свет |
| **Скандинавский** | Чистота, функциональность, близость к природе | белый дуб, серый бетон, шерсть | яркий дневной без теней |
| **Средиземноморский** | Тепло, жизнь, история | терракота, известняк, синие изразцы | жёсткий полуденный южный |
| **Индустриальный** | Честность конструкции, урбанизм | открытый кирпич, сталь, бетон | боковое заводское |
| **Новый классицизм** | Монументальность, традиция, качество | мрамор, дерево венге, латунь | торжественный верхний |
| **Organic Modern** | Природа в интерьере, живые формы | скруглённые формы, натуральный камень, растения | мягкий объёмный |
| **Брутализм-лайт** | Честная структура без агрессии | бетон архитектурный, стекло, металл | зенитный верхний |

---

## По типу объекта

### Жилое

- Молодая семья → Scandinavian + Organic Modern
- Состоятельный владелец 40+ → Japandi / Новый классицизм
- Творческий человек → Wabi-sabi / Индустриальный
- Загородный дом → Средиземноморский / Organic Modern

### HoReCa

- Ресторан авторской кухни → Wabi-sabi / Индустриальный
- Отель boutique → Japandi / Средиземноморский
- Спа / велнес → Japandi / Wabi-sabi (вода + дерево + камень)
- Кофейня → Scandinavian / Organic Modern

### Реставрация

- Историческое здание → Новый классицизм (сохранение) + Contemporary Intervention
- Советский модернизм → Брутализм-лайт + новая начинка
- Купеческое / доходное → Средиземноморский accent / Organic Modern

---

## Как выбирать стиль в разговоре

Задай клиенту 3 вопроса вместо показа таблицы:

1. "Три слова которые описывают как должно ощущаться это пространство?"
2. "Покажи картинку которая тебя цепляет — не обязательно архитектура, может быть что угодно."
3. "Что точно НЕ хочешь? Что было бы ошибкой?"

По ответам → выбери 1-2 стиля из каталога → предложи клиенту короткое описание одним предложением.
