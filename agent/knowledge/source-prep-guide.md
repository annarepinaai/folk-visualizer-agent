# Гайд по подготовке материалов — Folk Studio

Как подавать исходники агенту, чтобы получить максимальный результат.
Три уровня вовлечённости — выбирай по ситуации.

---

## Что агент делает с твоим материалом

```
Твой материал → Выбор режима → Промт → fal.ai → Рендер → Итерация
```

Чем точнее входящий материал — тем меньше итераций до нужного результата.

---

## Три уровня подготовки

### Уровень 1 — "Быстро, с нуля" (concept mode)

**Что даёшь:** только текст. Описание ощущения, стиля, клиента.

**Что пишешь агенту:**
```
Нужна визуализация для [ТИП: жилое / ресторан / спа / реставрация].
Клиент: [кто — семья с детьми / молодая пара / ресторатор].
Ощущение: [3 прилагательных — тёплое, тихое, природное].
Материалы точно будут: [дуб / штукатурка / терракота / бетон].
Свет: [утро / вечер / день / рассеянный / естественный].
```

**Что получаешь:** 3 варианта атмосферы за 30 секунд. Хорошо для первого разговора с клиентом.

**Ограничение:** геометрия генерируется случайно, не твой проект.

---

### Уровень 2 — "Мой проект, моя геометрия" (precise mode)

**Что даёшь:** скриншот или экспорт из SketchUp.

**Два варианта экспорта из SketchUp:**

**Вариант A — один экспорт (проще):**
- Стиль: Monochrome (белая модель без текстур)
- Включить: тени
- Не включать: фон, текстуры, цвета
- Формат: JPG, разрешение 1920×1080 минимум
- Результат: агент сохранит геометрию на ~70%

**Вариант B — два экспорта (лучший результат):**

*Экспорт 1 — Depth source (основное изображение):*
- Стиль: Monochrome + Fog style (туман создаёт имитацию depth map)
- Сохрани: `sketchup_depth.jpg`

*Экспорт 2 — Lineart для ControlNet (фиксирует рёбра):*
- Стиль: Hidden Line (только линии, белый фон)
- Тот же вьюпорт, та же камера
- Сохрани: `sketchup_lineart.jpg`

**Что пишешь агенту:**
```
Вот экспорт из SketchUp: [прикрепи sketchup_depth.jpg]
Lineart для точной геометрии: [прикрепи sketchup_lineart.jpg]

Тип: [жилое / HoReCa / реставрация]
Целевой стиль: [Japandi / Wabi-sabi / Скандинавский / другой]
Материалы: [пол — дубовый паркет ёлочкой / стены — известковая штукатурка / ...]
Свет: [натуральный, утро 9:00 / тёплый вечерний 19:00]
Атмосфера: [тихая / оживлённая / торжественная / уютная]
```

**Что получаешь:** рендер твоей геометрии в выбранном стиле. Если дал два экспорта — стены, углы и проёмы сохраняются точно.

---

### Уровень 3 — "Правка конкретного элемента" (edit mode)

**Когда использовать:** уже есть готовый рендер, нужно поменять один материал или деталь.

**Что даёшь:** готовый рендер + текстовое описание что именно изменить.

**Примеры команд для edit-режима:**
```
"Замени напольное покрытие на белый мрамор с серыми прожилками"
"Сделай стену левую из тёмного дуба вместо штукатурки"
"Поменяй освещение на вечернее, добавь тёплые подвесные лампы"
"Убери людей из кадра"
"Добавь живые растения в углу слева"
```

**Правило:** одна команда = одно изменение. Не "поменяй пол, стены и свет" — это три отдельных запроса.

## Как описывать материалы — словарь точности

Вместо общих слов используй конкретику. Агент передаёт это напрямую в промт.

| Общее слово | Точное описание |
|-------------|----------------|
| "дерево" | `natural oak herringbone parquet 70mm strips` / `dark walnut vertical cladding` / `reclaimed pine boards` |
| "камень" | `travertine tiles warm beige` / `black slate honed` / `limestone rough-cut` |
| "штукатурка" | `tadelakt plaster warm sand tone` / `lime wash white` / `exposed concrete formwork texture` |
| "тёплый свет" | `warm amber afternoon light 16:00, golden hour shadows` |
| "уютно" | `inhabited warmth, layered textiles, soft shadows, fresh flowers` |
| "современно" | (избегай) → лучше: `clean lines, essential elements only, breathing room` |

## Что указывать о проекте — минимальный чеклист

При первом запросе по новому объекту — дай эти данные. Агент сам спросит по одному, но если сразу — работаем быстрее.

```
□ Тип объекта: жилое / ресторан / спа / отель / офис / реставрация
□ Площадь примерно: [м²]
□ Высота потолков: [м]
□ Что точно будет в проекте (материалы, которые уже решены)
□ Три прилагательных как должно ОЩУЩАТЬСЯ
□ Референс — хотя бы одна картинка (не обязательно архитектура)
□ Что точно НЕ хочешь (ошибка была бы...)
□ Для кого: кто будет жить/работать/отдыхать
□ Свет: натуральный / искусственный / время суток
```

## Итерация — как давать правки

После первых рендеров агент покажет варианты A / B / C. Твои правки:

**Работает хорошо:**
- "Вариант B, но теплее и без людей"
- "Пол как в B, свет как в A"
- "Этот же, но добавь ощущение высоты"
- "Более реалистично, добавь деталей"

**Работает плохо:**
- "Сделай красивее" — нет критерия
- "Переделай полностью" — лучше запустить новый concept
- "Как у Zaha Hadid" — слишком абстрактно, дай конкретную картинку

**Правило:** "мне нравится [что конкретно] + хочу изменить [что конкретно]" — это идеальная правка.

## Быстрые сценарии для Folk Studio

### Сценарий: клиент приходит завтра, нужно показать варианты

```
1. concept mode, только текст → 3 атмосферы за 90 сек
2. Клиент выбрал направление
3. precise mode с SketchUp-экспортом → 3 варианта геометрии
4. Клиент выбрал один → edit mode для правок деталей
5. final mode → финальный 4K для презентации
```

### Сценарий: показать один проект в нескольких стилях

```
1. Экспортируй из SketchUp: monochrome вид фасада
2. precise mode: "жилой фасад, дерево + штукатурка, вечер"
3. precise mode: "тот же фасад, тёмный кирпич, урбанистика"
4. precise mode: "фасад, белая штукатурка, средиземноморский"
→ Три стилевых направления одного объекта для Behance
```

### Сценарий: концепт для клиента (ресторан + спа)

```
1. concept mode: "HoReCa, ресторан авторской кухни, [город/регион]"
   → Быстро найти атмосферу без модели
2. После первого разговора с клиентом
3. Уточнить материалы → precise mode с его планом
```

## Где хранить исходники

```
projects/<название-объекта>/
  viz-context.md      — контекст (агент создаёт при первом intake)
  source/
    sketchup_depth.jpg    — monochrome экспорт с туманом
    sketchup_lineart.jpg  — hidden line экспорт
    reference_01.jpg      — референс от клиента
    reference_02.jpg
  renders/              — финальные рендеры (агент кладёт в output/renders/)
```
