Инструмент

Четыре режима рендера

Агент выбирает режим автоматически по задаче. Ты можешь указать явно.

concept

Концепт

Быстрые атмосферы из текста. Для поиска направления и первого разговора с клиентом.

⏱ 30 сек · дёшево · геометрия случайная
precise

Точный

SketchUp / ArchiCAD экспорт → фотореализм. Геометрия сохраняется. Главный рабочий режим.

⏱ 40–60 сек · средне · геометрия твоя
edit

Правка

Меняет один элемент в готовом рендере. «Сделай стену из дуба» — и только стена меняется.

⏱ 5–10 сек · дёшево · точечно
final

Финал

4K для клиентской презентации и Behance. Запускается последним, один вариант.

⏱ 2–3 мин · дороже · максимум

Типичный цикл: concept → precise → edit → final
Для срочной задачи: precise → edit → final

Что ты даёшь агенту

Три уровня подготовки

01
Только текст
concept mode · атмосфера за 30 сек

Когда нет модели или нужно быстро найти направление для клиента. Пишешь агенту:

# Что написать агенту Нужна визуализация для [жилое / ресторан / спа] Клиент: [семья / молодая пара / ресторатор] Ощущение: [3 слова — тёплое, тихое, природное] Материалы точно будут: [дуб / штукатурка / терракота] Свет: [утро / вечер / рассеянный]

Результат: 3 варианта атмосферы. Геометрия генерируется случайно — это нормально для поиска направления.

02
Экспорт из программы
precise mode · твоя геометрия сохранена

Основной рабочий режим. Агент получает твою реальную геометрию и одевает её в стиль.

Напиши агенту вместе с файлом:

# Прикрепи файл + напиши это Вот экспорт из [SketchUp / ArchiCAD]: [файл] Тип: [жилое / ресторан / реставрация] Стиль: [Japandi / Wabi-sabi / Скандинавский] Пол: [дубовый паркет ёлочкой 70мм] Стены: [известковая штукатурка, тёплый тон] Свет: [натуральный, утро 9:00 через высокие окна] Атмосфера: [тихая / оживлённая / торжественная]

Для максимального контроля — два экспорта из одного вьюпорта (см. раздел «Экспорт»). Тогда стены, углы и проёмы сохраняются точно.

03
Правка конкретного элемента
edit mode · один элемент за 5 секунд

Есть готовый рендер, нужно поменять что-то одно. Прикрепи рендер и напиши:

# Одна команда = одно изменение "Замени напольное покрытие на белый мрамор с серыми прожилками" "Сделай левую стену из тёмного дуба вместо штукатурки" "Поменяй на вечернее освещение, добавь тёплые подвесные лампы" "Убери людей из кадра" "Добавь живые растения в углу слева"

Не "поменяй пол, стены и свет" — это три отдельных запроса. Одна команда, один элемент — самый быстрый результат.

Технический раздел

Экспорт из SketchUp и ArchiCAD

Вариант A — один экспорт (быстро)

Геометрия сохраняется на ~70%. Достаточно для большинства задач.

Выбери стиль: Monochrome

View → Styles → Monochrome. Белая модель без текстур и цветов.

Включи тени

View → Shadows → включить. Солнце на 10-14:00, средняя яркость.

Настрой вьюпорт

Угол камеры, перспектива. Это и будет финальный кадр рендера.

Экспортируй

File → Export → 2D Graphic → JPG. Разрешение: 1920×1080 минимум. Сохрани как sketchup_mono.jpg

Вариант B — два экспорта (максимальный контроль)

Точная фиксация рёбер через ControlNet. Стены, углы, проёмы — как в модели.

Настрой вьюпорт один раз — не трогай до конца

Оба экспорта должны быть с одной камеры, одинаковое разрешение.

Экспорт 1 — Depth source

Стиль: Monochrome + включи Fog (View → Fog). Туман создаёт глубину. Сохрани как sketchup_depth.jpg

Экспорт 2 — Lineart (рёбра)

Стиль: Hidden Line (белый фон, только чёрные линии, без заливки). Тот же вьюпорт, та же камера. Сохрани как sketchup_lineart.jpg

Передай агенту оба файла

Прикрепи оба изображения. Напиши: «вот depth и lineart из SketchUp». Агент сам применит ControlNet.

ArchiCAD → точный рендер

ArchiCAD даёт более точную геометрию чем SketchUp. Два пути в зависимости от того что есть.

Путь 1 — из 3D-окна (быстро)

Открой 3D-окно

Window → 3D. Выбери нужный вид камерой или через Orbit.

Переключись в Wireframe или Hidden Line

View → 3D View Mode → Hidden Line (скрытые линии). Белая модель, без материалов.

Сохрани вид

File → Save as → PNG/JPG. Разрешение: установи в параметрах сохранения 1920×1080+. Сохрани как archicad_wire.jpg

Передай агенту

Этот файл идёт как --image в precise mode. Сила трансформации: 0.60–0.70 (геометрия сохраняется жёстко).

Путь 2 — через Cinema 4D / BIMx (для двух экспортов)

Если нужен максимальный контроль геометрии как в SketchUp Вариант B:

Экспортируй OBJ/FBX из ArchiCAD

File → Save as → 3D Model Files → OBJ или FBX. Без текстур (Only Surfaces).

Импортируй в Blender (бесплатно)

File → Import → OBJ. Настрой камеру как в ArchiCAD (тот же угол).

Рендер Depth map

В Blender: Cycles, добавить Depth Pass в Compositor → сохрани как depth.jpg

Рендер Edge/Lineart

Freestyle renderer в Blender → только рёбра, белый фон → сохрани как lineart.jpg

Передай агенту оба файла

Так же как SketchUp Вариант B: depth + lineart, precise mode.

Самый простой путь для ArchiCAD: 3D окно → Hidden Line → JPG экспорт. Геометрия сохранится на 65–75%, чего достаточно для большинства задач. Путь через Blender — когда нужна точность «как в портфолио».

Диалог с агентом

Как давать правки

После первых рендеров агент покажет варианты А / Б / В. Идеальная правка:

«Нравится [что конкретно] + хочу изменить [что конкретно]»
Работает
  • «Вариант Б, но теплее и без людей»
  • «Пол как в Б, свет как в А»
  • «Тот же, но добавь ощущение высоты»
  • «Более реалистично, больше деталей»
  • «Сохрани геометрию жёстче»
Не работает
  • «Сделай красивее» — нет критерия
  • «Переделай полностью» → новый concept
  • «Как у Zaha Hadid» → дай картинку
  • «Поменяй пол, стены и свет» → 3 запроса
  • «Мне не нравится» — что именно?

Быстрые модификаторы

ХочешьПишешь агенту
Теплее«добавь тепла» → warm amber tones, honey-colored light
Холоднее«холоднее» → cool north light, silver tones, morning clarity
Минималистичнее«меньше всего» → essential elements only, negative space
Уютнее«уютнее» → layered textiles, soft shadows, inhabited warmth
