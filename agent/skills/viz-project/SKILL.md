# Скилл /viz-project — Старт нового проекта

## Обязательные триггеры

Запускать при:
- "новый проект", "новый объект", "новый клиент"
- Первое упоминание конкретного объекта без существующего viz-context.md
- `/viz` запущен, но viz-context.md не найден

## Цель

Собрать достаточно данных о проекте для точного промпта. Задавать вопросы по одному. Не анкета — живой разговор.

---

## Процесс (7 вопросов, по одному)

```
Вопрос 1: Тип объекта
Вопрос 2: Что есть на руках
Вопрос 3: Целевое ощущение (3 слова)
Вопрос 4: Референс (любая картинка)
Вопрос 5: Главные материалы
Вопрос 6: Свет и время суток
Вопрос 7: Для кого / что важно конечному пользователю
```

**Правило:** задавать по ОДНОМУ. Не список. Слушать ответ → задавать следующий с учётом услышанного.

**Если "не знаю"** → предложи 3 варианта на выбор.

**Если клиент торопится** → минимум 3 вопроса (тип + ощущение + материал), остальное достраивай сам.

---

## Создание viz-context.md

После intake создай файл `projects/<slug>/viz-context.md`:

```markdown
# [Название проекта] — Визуальный контекст

**Тип объекта:** [жилое / HoReCa / реставрация / другое]
**Площадь / масштаб:** [если известно]
**Клиент (конечный пользователь):** [кто это]

## Ощущение
[3 слова + 1-2 предложения развернуто]

## Референсы
[ссылки на изображения или описание "как у..."]

## Материалы
- Пол: [конкретно]
- Стены: [конкретно]
- Акценты: [конкретно]

## Свет
- Тип: [естественный / искусственный / смешанный]
- Время суток: [утро / день / вечер / ночь]
- Характер: [мягкий / жёсткий / рассеянный / направленный]

## Стиль (из styles-catalog.md)
[выбранный стиль]

## Студия-референс (из studio-digests.md)
[выбранная студия + 1-2 её принципа применительно к этому проекту]

## Запреты
[что точно НЕ делать]

## История визуализаций
| Дата | Вариант | Реакция | Итог |
|------|---------|---------|------|
| — | — | — | — |
```

## Примеры Input → Output

### Пример

**Trigger:** "хочу сделать рендеры нового объекта, ресторан в Краснодаре"

**Процесс:**
```
Ок. Начнём разбираться. Что за ресторан — концепция уже есть?
[ждёт ответ]

[если "авторская кухня, что-то тёплое и необычное"]
Три слова про ощущение — как должно чувствоваться тому кто зашёл?
[ждёт ответ]

[если "камерно, тепло, как дома у друга"]
Фото пространства есть? Или начинаем с нуля?
...
```

**Output:** создан `projects/restoran-krasnodar/viz-context.md`
