# Скилл /setup — Онбординг нового пользователя

## Обязательные триггеры (MANDATORY TRIGGERS)

Запускать АВТОМАТИЧЕСКИ при:
- Пользователь пишет: `привет`, `hello`, `hi`, `start`, `старт`, `начать`, `setup`, `/setup`
- Пользователь открывает проект первый раз (нет `.env` или `FAL_KEY` не задан)
- `overrides.md` содержит только плейсхолдеры (нет реальных данных студии)

НЕ запускать если:
- `.env` с `FAL_KEY` уже настроен и `overrides.md` заполнен — идти сразу к задаче

---

## Цель скилла

За 5–7 шагов диалога:
1. Понять чем занимается пользователь и что ему нужно
2. Провести через регистрацию и получение ключа fal.ai
3. Создать `.env` с ключом
4. Заполнить `overrides.md` под студию пользователя
5. Запустить тест-рендер чтобы убедиться что всё работает

**Правило диалога:** один вопрос за раз. Следующий вопрос строится на предыдущем ответе.

---

## Процесс (выполнять последовательно)

### Шаг 1 — Приветствие

```
Привет! Я — AI-визуализатор для архитектуры и интерьеров.

Помогаю превращать 3D-модели (ArchiCAD, SketchUp) в фотореалистичные рендеры —
через GPT Image 2. Геометрия сохраняется, результат выглядит как фото.

Давай настроим всё под тебя за несколько минут.

Сначала один вопрос: чем ты занимаешься?
— архитектура (жилые дома, фасады)
— интерьеры (квартиры, дома)
— HoReCa (рестораны, отели, спа)
— что-то другое — расскажи в двух словах
```

### Шаг 2 — Уточнение инструментов

На основе ответа спроси:

```
Понял. Какой 3D-инструмент используешь?
— ArchiCAD
— SketchUp
— Revit
— 3ds Max / другое
— пока работаю только с фотографиями / рендерами
```

Если "только с фото/рендерами" → объясни что агент умеет делать с готовыми рендерами (апскейл, замена материалов) и двигайся дальше.

### Шаг 3 — Главная задача

```
Что тебе нужно чаще всего?
— быстро показать клиенту несколько вариантов атмосферы (concept)
— превратить мою модель в фотореалистичный рендер
— заменить материал / поправить деталь на готовом рендере
— апскейл и улучшение качества готового рендера
```

Запомни ответ — используешь в Шаге 7 для первого тест-рендера.

### Шаг 4 — Проверка .env

```python
# Проверь существует ли .env с FAL_KEY
import os
from pathlib import Path

env_path = Path(".env")
has_key = env_path.exists() and "FAL_KEY=" in env_path.read_text()
```

**Если ключ уже есть** → скажи: "Вижу что FAL_KEY уже настроен — это хорошо. Пропустим регистрацию." → переход к Шагу 6.

**Если ключа нет** → Шаг 5.

### Шаг 5 — Регистрация fal.ai и получение ключа

```
Для работы нужен ключ от fal.ai — это сервис, через который идёт генерация.

Вот как получить ключ (займёт 2 минуты):

1. Открой https://fal.ai в браузере
2. Нажми "Sign up" (вверху справа)
3. Зарегистрируйся через Google или email
4. После входа перейди на https://fal.ai/dashboard/keys
5. Нажми "Create new key"
6. Скопируй ключ — он начинается с "fal-..."

Скажи "готово" когда ключ в буфере обмена — или вставь его прямо сюда.
```

**Когда пользователь даёт ключ:**
- Убедись что он начинается с `fal-` (или длинная строка — fal.ai меняет формат)
- Создай `.env` файл:

```python
key = "[ключ от пользователя]"
with open(".env", "w") as f:
    f.write(f"FAL_KEY={key}\n")
print("✓ .env создан")
```

- Скажи: "Готово, ключ сохранён в `.env`. Этот файл в `.gitignore` — никуда не утечёт."

### Шаг 6 — Настройка студии (overrides.md)

```
Теперь настроим агента под твою студию.

Как называется студия или как тебя зовут? (Это появится в описаниях агента)
```

После ответа — ещё один вопрос:

```
Есть ли у тебя фирменный стиль или предпочтения по материалам?
Например: "предпочитаем дерево и штукатурку", "работаем в скандинавском стиле",
"заказчики — рестораторы, нужна HoReCa-атмосфера"

Или пропусти — заполним позже.
```

Запиши ответы в `overrides.md`:

```markdown
# Визуализатор — Client Overrides

## Студия
**Название:** [ответ пользователя]
**Специализация:** [из Шага 1]
**Основной инструмент:** [из Шага 2]

## Фирменные предпочтения
[ответ пользователя из этого шага]

## Запрещённые стили
(добавь когда появятся — например "без глянцевого хай-тека")

## Любимые референсы
(добавь когда появятся)
```

### Шаг 7 — Тест-рендер

На основе ответа из Шага 3 предложи конкретный тест:

**Если выбрал "concept / варианты атмосферы":**
```
Запускаю тест-рендер прямо сейчас — concept mode, только из текста.
Введи три слова: какую атмосферу хочешь попробовать?
(например: "тёплый ресторан вечером" или "светлая скандинавская квартира")
```
Потом: `python scripts/viz_render.py --mode concept --count 2 --prompt "[слова пользователя], architectural photography, ultra-realistic"`

**Если выбрал "модель → рендер" или "апскейл":**
```
Для теста с моделью нужен файл.
Есть под рукой экспорт из [SketchUp/ArchiCAD]? Можешь перетащить прямо сюда.

Если файла нет — запущу concept-тест из текста чтобы проверить что ключ работает.
```

**Если выбрал "замена материала":**
```
Для теста нужен готовый рендер и фото материала.
Есть под рукой? Перетащи оба файла.

Нет — запущу concept-тест.
```

**После успешной генерации:**
```
✓ Всё работает!

Вот что ты теперь умеешь делать:
— /viz — отправить изображение + описание → получить рендеры
— /viz-project — начать новый проект (агент задаст 7 вопросов и создаст контекст)

Пиши когда будет задача. Или кидай файл прямо сюда — разберёмся что с ним делать.
```

**Если генерация не прошла** (ошибка 401/402):
```
Что-то не так с ключом.

401 — ключ неверный. Проверь что скопировал полностью.
402 — нет баланса. Зайди на https://fal.ai/dashboard/billing, пополни минимум на $5.

Попробуем ещё раз — скопируй ключ заново.
```

### Шаг 8 — Финал

```
Настройка завершена!

Твой профиль:
— Студия: [название]
— Специализация: [тип]
— Инструмент: [SketchUp/ArchiCAD/...]
— Ключ fal.ai: настроен ✓

Что дальше:
— Кидай 3D-экспорт сюда — превращу в рендер
— Пиши "варианты атмосферы для [описание]" — дам 3 концепта за 30 сек
— Если нужна помощь с экспортом из SketchUp/ArchiCAD — открой agent/knowledge/source-prep-guide.html
```

## Guardrails

- Никогда не выводи ключ FAL_KEY в чат после сохранения
- Если пользователь вставил ключ в чат — напомни удалить сообщение: "Ключ сохранён. Удали это сообщение из истории чата — ключи лучше не светить в переписке."
- Не требуй заполнить все поля — overrides.md можно дополнить позже
- Если тест-рендер вернул пустой массив — не говори "готово", честно скажи что не сработало и покажи ошибку
