# Скилл /viz — Архитектурная визуализация

## Обязательные триггеры (MANDATORY TRIGGERS)

Запускать АВТОМАТИЧЕСКИ при:
- Пользователь загружает изображение (фото, эскиз, план, белая модель) + описывает что хочет
- Пишет: "сделай рендер", "визуализируй", "покажи как будет выглядеть", "хочу увидеть"
- Пишет: "изменить на [стиль]", "другой вариант", "теплее/холоднее/светлее"

## Входные данные

| Вход | Обязательно | Описание |
|------|------------|----------|
| Изображение | Желательно | Фото, эскиз, план, скриншот модели |
| Описание | Да | Текст или голос — что хочет получить |
| Проект | Нет | Если указан → загрузить viz-context.md |

Если изображения нет → спросить: "Есть фото или эскиз пространства? Или работаем с нуля из описания?"

## Процесс (выполнять последовательно)

### Шаг 1 — ANALYZE (если есть изображение)

Прочитай изображение и опиши вслух клиенту:
```
"Смотрю на изображение:
— Тип пространства: [жилое / HoReCa / другое]
— Геометрия: [пропорции, высота, форма]
— Что уже решено: [материалы, свет, планировка]
— Что открыто: [что можно менять]"
```

### Шаг 2 — CONTEXT

1. Проверь: есть ли `projects/<slug>/viz-context.md`?
   - Есть → загрузи, работай из него
   - Нет → это новый проект, запусти `/viz-project` (intake) ПЕРЕД генерацией
2. Grep `failures.md` на ключевые слова (тип объекта, стиль)

### Шаг 3 — STUDIO DIGEST

Из `knowledge/studio-digests.md` выбери 1 студию по типу объекта:
- Жилое → MIR или Dbox
- HoReCa → Forbes Massie или Neoscape
- Реставрация → Forbes Massie
- Концепт → Luxigon

Прими 1-2 принципа этой студии в промпт.

### Шаг 4 — BUILD PROMPT

Собери промпт по шаблону из `knowledge/prompt-library.md`:

```
[ТИП_ИЗОБРАЖЕНИЯ]: architectural interior/exterior photography
[ОБЪЕКТ]: [из context]
[СТИЛЬ]: [из context или styles-catalog]
[МАТЕРИАЛЫ]: [конкретные, из context]
[СВЕТ]: [конкретный, из context]
[АТМОСФЕРА]: [из studio digest]
[ЛЮДИ]: [есть / нет / hint of presence]
[КАМЕРА]: [объектив, диафрагма]
[КАЧЕСТВО]: ultra-realistic, 8K, award-winning architectural photography
[ANTI-SLOP]: NOT glossy CGI, NOT generic, NOT artificial
```

Подготовь **3 варианта промпта** с разными акцентами:
- Вариант A: акцент на **материалы и тактильность**
- Вариант B: акцент на **свет и атмосферу**
- Вариант C: акцент на **пространство и масштаб**

### Шаг 5 — GENERATE

Запусти скрипт для каждого варианта:

```bash
python scripts/viz_render.py \
  --image [путь к загруженному изображению] \
  --prompt "[промпт варианта]" \
  --count 1 \
  --strength 0.75
```

Если изображения нет — используй только промпт (txt2img, без `--image`).

### Шаг 6 — PRESENT

Покажи результаты с коротким описанием каждого:

```
Вариант 1 [A — материалы]: [одна строка что акцентировано]
Вариант 2 [B — свет]: [одна строка]
Вариант 3 [C — пространство]: [одна строка]

Какой ближе? Или что поменять?
```

### Шаг 7 — ITERATE

При правке от клиента:
- "теплее" → добавь `warm amber tones, honey light`
- "больше дерева" → усиль материал в промпте
- "другое дерево/камень/металл" → замени конкретику материала
- "убери людей" → удали human presence из промпта
- "более реалистично" → подними `num_inference_steps` до 40+
- "сохрани геометрию" → снизь `strength` до 0.55-0.65
- "полностью переделай" → strength 0.9+

НЕ перегенеришь всё с нуля при мелкой правке. Меняй только нужный элемент промпта.

### Шаг 8 — SAVE

После завершения серии → обнови `memory.md`:
```
## [Дата] — [Название проекта]
- Тип: [жилое/HoReCa/реставрация]
- Стиль выбран: [какой]
- Что зашло: [реакция клиента]
- Что не зашло: [что отвергли]
- Лучший промпт: [финальный вариант]
```

## Примеры Input → Output

### Пример 1

**Input:** [фото пустой комнаты с кирпичными стенами] + "хочу уютный ресторан, что-то тёплое"

**Output:**
```
Смотрю на изображение:
— Тип: коммерческое пространство ~80м²
— Геометрия: высокие потолки ~4м, кирпич открытый, окна боковые
— Что решено: структура, кирпич оставляем
— Что открыто: пол, освещение, мебель, зонирование

Для ресторана с кирпичом — Forbes Massie работают через теплый вечерний свет и
обитаемость. Буду делать три варианта:

A — Итальянский бистро: терракотовый пол, деревянные столы, тёплые подвесные лампы
B — Модный urban: тёмный дуб, стальные детали, направленный свет
C — Wabi-sabi: необработанное дерево, глина, свечи как основной источник

[генерация...]

Вариант 1: бистро, терракота, обеденный свет 19:00
Вариант 2: urban, тёмное дерево, атмосфера бара
Вариант 3: wabi, глина и свечи, очень тихо

Какой ближе?
```

### Пример 2

**Input:** [эскиз план квартиры от руки] + "скандинавский, светлый, для молодой пары"

**Output:**
```
Вижу план: однокомнатная, гостиная совмещена с кухней, спальня отдельно.

Для скандинавского — беру MIR: рассеянный северный свет, честные материалы.

A — утро: белый дуб пол, льняной диван, мягкий утренний свет
B — день: то же, но полдень через шторы, яркость
C — вечер: тёплое торшерное, уютная версия

[генерация...]
```
